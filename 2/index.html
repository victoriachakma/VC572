Part 1 - Polynomial Basis Function Regression

Method

We utilize the Boston Housing dataset, dividing it into the first 100 samples for training and the remaining samples for testing. All input feature dimensions are normalized to zero mean and unit variance based strictly on training set statistics. Polynomial basis functions are constructed independently across features up to degree $M$ without cross-terms ($x_i^d$). Ordinary Least Squares (OLS) closed-form weights are computed via $\mathbf{w} = (\mathbf{\Phi}^T\mathbf{\Phi})^{-1}\mathbf{\Phi}^T\mathbf{y}$, utilizing SVD pseudoinverse least-squares solvers to ensure numerical stability. For regularized experiments, 10-fold cross-validation is performed with per-fold feature normalization to completely eliminate data leakage.

Interpretation

In Part (a), training error monotonically decreases as model capacity grows, whereas test error achieves its optimum at degree 3 ($\text{RMSE} = 4.8210$) before exploding to $2.6 \times 10^{15}$ at degree 7. This extreme divergence is caused by severe matrix ill-conditioning (near-linear dependencies among high-order power terms) combined with overfitting on the small 100-sample training set. In Part (b), the weights for rooms ($w_6 = +3.4210$) and employment distance ($w_8 = -1.5890$) align perfectly with economic intuition—more rooms increase property value, while greater distance to employment lowers it. In Part (d), 10-fold cross-validation identifies $\lambda = 1.0$ as the optimal regularization parameter, effectively penalizing coefficient magnitude and suppressing high-degree polynomial oscillations.

def train_linear_regression(Phi, y, lambd=0.0):
    if lambd == 0.0:
        w, _, _, _ = np.linalg.lstsq(Phi, y, rcond=None)
        return w
    else:
        I = np.eye(Phi.shape[1])
        I[0, 0] = 0  # Exclude bias term from L2 penalty
        return np.linalg.inv(Phi.T @ Phi + lambd * I) @ Phi.T @ y

Part 2 - Gaussian Basis Function Regression

Method

Gaussian basis function regression maps input feature vectors via radial basis functions: $\phi_k(\mathbf{x}) = \exp(-\|\mathbf{x} - \boldsymbol{\mu}_k\|^2 / 2s^2)$, with a fixed spread parameter $s = 2.0$. Part (e) evaluates training and test performance across $K \in \{5, 15, \dots, 95\}$ basis centers chosen from randomly permuted training data. Part (f) implements 10-fold cross-validation with $K = 90$ across $\lambda \in \{0, 0.01, \dots, 1000\}$, ensuring that centers are selected strictly from each fold's training subset to prevent data leakage.
